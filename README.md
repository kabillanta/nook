Nook is a closed, text-first commitment platform designed for college communities, focused on accountability through visibility rather than engagement. Authenticated users publicly declare time-bound commitments, which are recorded as pending by default and remain immutable after creation. Users later mark outcomes as kept or broken from their profile, while the system automatically marks unresolved commitments as broken once deadlines pass. Other users cannot interact with commitments and instead act as passive witnesses, creating quiet social pressure through shared memory and reputation. The platform uses Firebase Authentication for secure identity management, with a custom backend enforcing authorization, commitment lifecycle logic, and data persistence via RESTful APIs. By emphasizing immutable records, time-based state transitions, and reputation over likes or comments, Nook demonstrates clean full-stack architecture and a psychologically grounded approach to accountability.
